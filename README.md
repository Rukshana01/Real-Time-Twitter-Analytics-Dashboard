# Real-Time-Twitter-Analytics-Dashboard

Project Overview

This project is a Twitter Data Analytics Dashboard developed using Microsoft Power BI as part of a Data Analytics internship.

The project focuses on analyzing tweet-level data to understand tweet interactions, engagement rates, media performance, engagement trends, and top-performing tweets.

The raw Twitter dataset was transformed into meaningful visualizations using Power BI, DAX, filtering, aggregation, and time-based analysis.

The project consists of six analytical tasks, with each task addressing a specific aspect of Twitter engagement.

Project Objectives:
The main objectives of this project are:
Analyze Twitter engagement and interaction metrics.
Compare different types of tweet engagement.
Analyze media views and media engagements.
Identify engagement trends over time.
Identify the top-performing tweets.
Apply business rules and conditional filters.
Create meaningful Power BI visualizations.
Develop practical skills in DAX and data analytics.
Convert raw data into clear and actionable insights.
